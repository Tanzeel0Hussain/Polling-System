# Legacy Academic Version

This folder contains the original Java Swing source code from the university project.

The maintained application is now under `src/main/java/com/tanzeel/polling/` and includes SQLite persistence, BCrypt password hashing, role-based authentication, poll management, duplicate-vote protection, tests, and Maven/CI support.

The legacy files are kept only for historical/reference purposes. Compiled `.class` files have been removed from version control.
